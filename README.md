# Libreta de Barras

App para el móvil para escribir letras de rap: rimas en español, sílabas por barra, beat de fondo, grabación de voz e ideas sueltas.

Se instala desde Chrome en Android: abre la dirección de GitHub Pages y pulsa **⋮ → Instalar aplicación**.
Las letras y grabaciones se guardan solo en el móvil (Temas → Guardar copia para sacar una copia).

Diccionario de rimas: FrequencyWords (Hermit Dave, CC BY-SA 4.0) y an-array-of-spanish-words (MIT).
